🎬 CineVerse – Movie Ticket Booking System

CineVerse is a full-stack movie ticket booking web application built using React.js, Node.js, Express.js, and MongoDB.

The project allows users to browse movies, view movie details and shows, select seats, and manage their bookings. It also includes an admin section for managing movies, shows, and bookings.

🚀 Features


👤 User Features :


User registration and login


Browse movies


View movie details


View available shows


Select seats


Movie ticket booking


View bookings


Add movies to favorites


Responsive user interface


🔐 Admin Features:


Admin dashboard


Manage movies


Manage shows


View bookings


Manage movie-related information


💳 Payment:


Payment integration is currently under development.
